Business Board v3.9.0

- Renamed Checklist UI to Sub Tasks.
- Task cards now show sub-task progress such as 0/3, 1/3, 2/3, 3/3.
- Clicking the main task checkbox when sub tasks exist opens the Sub Tasks modal instead of completing immediately.
- All sub tasks must be completed before the parent task can be completed; this is enforced in both the UI and server-side logic.
- The parent task auto-completes when the final sub task is checked.
- Sub-task progress is stored per actual occurrence, so recurring tasks start fresh for every recurrence.
- Reopening a completed parent task resets the sub-task progress for that occurrence.
- Future recurring occurrences remain virtual; sub-task progress rows are created only as users interact with a due/future occurrence.
- Sub-task completion/reopen events are included in the activity log.
