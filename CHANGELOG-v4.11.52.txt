Workboard v4.11.52
- Updated Task Assigned WhatsApp template to three variables: Task, Assigned To, and Due Date.
- Due Date now uses dd/mm/yyyy format.
- If a due time is filled, it is appended in the same field, for example: 29/09/2026 12:50.
- If no due time is filled, only the date is sent.
- Task Assigned recipient name is sent as Assigned To.
- Other WhatsApp message types remain unchanged apart from the standardized dd/mm/yyyy due-date formatting generated by the shared formatter.
